#Rateat

O RateAt é um site de avaliação de restaurantes.

Os usuários podem:

Pesquisar restaurantes
Ver detalhes de cada restaurante (nota, endereço, categoria)
Avaliar dando uma nota de 1 a 5 e deixando um comentário
Criar conta e fazer login
